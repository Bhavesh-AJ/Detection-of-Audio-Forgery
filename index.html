Four-stage detection pipeline.

The page mirrors the repository workflow: metadata loading, feature extraction, sequence modeling, and saved evaluation artifacts.

Metadata

Labels are loaded from meta.csv and mapped into bona-fide as 0 and spoof as 1.

Features

Librosa extracts 40 MFCC coefficients, padded or trimmed to 300 frames. RF baseline uses 12-dim chroma features.

Modeling

CNN-BiLSTM learns temporal MFCC patterns. Random Forest classifies chroma feature vectors as a conventional ML baseline.

Evaluation

Confusion matrix and ROC curve are generated for both models, with metrics saved as evaluation artifacts.

Two-model architecture.

CNN-BiLSTM for deep temporal learning, Random Forest for interpretable baseline comparison.

CNN-BiLSTM Architecture

Input shape is 300 time frames by 40 MFCC features.

Input 300 × 40 MFCC sequence
Conv1D 64 filters, kernel size 3, ReLU, max pooling, batch normalization
Conv1D 128 filters, kernel size 3, ReLU, max pooling, batch normalization
BiLSTM 64 units in both directions for temporal context
Dense Dropout 0.3, 64-unit ReLU layer, sigmoid output

Random Forest Architecture

Input is a 12-dimensional mean chroma feature vector per audio file.

Input 12-dim mean chroma feature vector
Forest 100 estimators, max depth 20, random state 42
Parallel n_jobs=−1, all CPU cores used during training
Output predict_proba → spoof probability score [0, 1]
